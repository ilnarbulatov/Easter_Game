##  Браузерная аркадная мини-игра с глобальной таблицей лидеров, разработанная для интерактивного вовлечения аудитории.


---

##  Механика игры
* **Цель:** ловить падающие пасхальные куличи и яйца в корзину, набирая максимальное количество очков.
* **Усложнение:** необходимо уклоняться от несъедобных препятствий. Пропуск хотя бы одного яйца или столкновение с препятствием завершает раунд.
* **Рейтинг:** по окончании игры пользователь может сохранить свой результат в общую таблицу лидеров.

---

##  Архитектура и стек технологий

Проект построен по **Serverless-архитектуре**, что обеспечивает нулевую стоимость хостинга, высокую отказоустойчивость и полную изоляцию базы данных от клиента:

* **Frontend:** Vanilla JavaScript (ES6+ модули), HTML5, CSS3. Хостинг и CDN — **Cloudflare Pages**.
* **Backend / API Gateway (`worker/worker.js`):** **Cloudflare Workers** — проксирует запросы к БД, выполняет серверную валидацию результатов и обеспечивает резервное кэширование.
* **База данных:** **Airtable** (хранение никнеймов и таблицы рекордов через REST API).

---

##  Безопасность, античит и отказоустойчивость

В проекте реализована **двухуровневая защита** (клиент + сервер) от накрутки рекордов и утечки данных:

### 1. Инфраструктурная безопасность и отказоустойчивость (`worker/worker.js`)
* **Изоляция секретов:** API-токены Airtable и ID базы хранятся исключительно в зашифрованных переменных окружения (`Environment Variables / Secrets`) внутри Cloudflare Worker (`env.AIRTABLE_TOKEN`, `env.BASE_ID`) и полностью исключены из кодовой базы.
* **Серверная валидация (Server-Side Anti-Cheat):** бэкенд проверяет каждый входящий запрос `/api/save-score` на физическую правдоподобность:
  * ограничение максимально возможного счёта за раунд;
  * сверка набранных очков с длительностью игровой сессии (`gameDuration`);
  * контроль аномального процента выпадения бонусных («золотых») предметов.
* **Fallback-кэширование и Graceful Degradation:** при временной недоступности API Airtable воркер автоматически переключается на резервное хранение рекордов в оперативной памяти инстанса (`memoryScores`), а фронтенд корректно обрабатывает сетевые сбои без зависания интерфейса.

### 2. Клиентская защита (`scripts/anticheat.js`)
* **Защита памяти:** перехват сеттера глобальной переменной `window.score` через `Object.defineProperty` для блокировки ручной подмены счёта через DevTools.
* **Поведенческая аналитика (Behavioral Analysis):** отслеживание интервалов между кликами (детект автокликеров < 30 мс) и анализ геометрии траектории курсора.
* **Детект автоматизации:** проверка флагов `navigator.webdriver` и `User-Agent` для отсечения headless-браузеров (Selenium, Puppeteer, Playwright).

##  Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Easter_Game
   ```
2. Запустите локальный веб-сервер (например, через **Live Server** в VS Code или встроенный модуль Python, чтобы корректно работали ES-модули и CORS-политики):
   ```bash
   python -m http.server 8000
   ```
3. Откройте в браузере `http://localhost:8000`.
